# Bundled Chinese recognition model

The quantized ONNX files and token table are unmodified files from the [sherpa-onnx Chinese Zipformer 14M release archive](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23.tar.bz2), SHA-256 `2cbd71b640d9c37d3784f29367333a4577b0398b62e9deeed418170b081cba8b`.

The [ONNX publisher](https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23) and [original model publisher](https://huggingface.co/marcoyang/sherpa-ncnn-streaming-zipformer-zh-14M-2023-02-23) mark the model Apache-2.0. The license text ships under `assets/licenses/sherpa-onnx.txt`. KIGTTS adds the local pack manifest and checksums; full-precision models and test recordings are not bundled.
